# Expense Tracker

## Problem Statement

Create a console-based Expense Tracker program in Python that allows the user to record expenses and view total spending.

The program allows the user to:

- Add an expense with date, category, description, and amount.
- View all recorded expenses.
- Calculate total spending.
- Exit the program.

The expenses are stored in a list in the form of dictionaries.

The program uses loops, if-else statements, lists, dictionaries, and basic input/output.
